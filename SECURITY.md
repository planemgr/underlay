# Security

## Supported Versions

The versions below are actively supported. Please only report issues related
to the active versions.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.3   | :white_check_mark: |
| < 0.1.3 | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Please use the GitHub "Security and quality" feature to report vulnerabilities.
